Install Binky Connect

Connect your device to your Binky computer. Choose your device below to see what is available.

Binky is in real-world testing. Android and Windows test apps are available below. You need a configured Binky computer to complete pairing. iPhone installation is still being prepared.

Android

Available test release · Version 0.3.8 · Android 8 or later

The signed Android app provides the tested private connection and supported message capture.

Download Binky Connect for Android

APK download · 15.2 MiB · Download checksum

  1. Download the app on your Android device and open the downloaded file. Android may ask you to allow your browser to install this app.
  2. Open Binky Connect and go to Messages & setup.
  3. Use your private Binky connection link or link file to pair with your own Binky. Follow the app’s connection and permission prompts.

Already using Binky Connect? Install this as an update and keep the existing app and its data.

WhatsApp and Messenger capture supported Android notifications. This does not download complete historical chat archives.

Message history test update

For existing Android testers · Version 0.3.9 · Android 8 or later

This update adds private WhatsApp and Messenger account-linking screens for the message-history trial. It requires the matching history service on your Binky computer. Account linking and historical coverage are still being tested.

Download the message history test update

Signed APK · 15.4 MiB · Download checksum

Install this as an update, keeping your existing app and data. Open Messages & setup → Connect message history. Enter account details only inside Binky Connect over its private connection.

This download contains no private pairing profile or account credentials. The trial does not establish complete history or media recovery.

Windows

Windows test release · Version 0.1.0 · Windows 10/11, 64-bit

Use your own Binky in your normal browser, at home or away. Keep Binky Connect running while you use it. No Tailscale or SSH is needed for normal access.

Download Binky Connect for Windows

Windows installer · 54.8 MiB · Download checksum

  1. Download and open the installer. This test release is unsigned, so Windows may show an unknown-publisher warning.
  2. Open Binky Connect and choose Pair my Binky.
  3. Give the displayed approval code to your Binky operator. Access begins only after they approve this laptop.
  4. When the status reads Connected privately, choose Open Binky.

The download contains no account credentials or private pairing profile. It connects your browser to Binky; it does not import messages from your laptop. The server-side Windows connection service must be configured on your Binky.
